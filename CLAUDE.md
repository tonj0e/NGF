# Project brain

This project has an Obsidian vault in `docs/`. **Read `docs/00 BRAIN.md` first**, then the brain note of the section you are working in (`docs/<section>/<Section> Brain.md`).

- Notes are written from the code. If code and notes disagree, the code wins: fix the note.
- After a change that alters how something works, update the matching note and add a line to today's note in `docs/10 Daily Log/`.
- Never write secret values (keys, tokens, passwords) in notes or code. Env variable names are fine.
- Security fixes follow `docs/07 Security/Security Fix Plan.md`; back up the project before starting.
