## Agent My Route: verify inside the page (cuts Google map cost)
- Problem: leaving My Route for Assigned Verifications and back rebuilt the Google map each time (billed per map load; ~30 stops/day/agent).
- Now: on a stop, "I have reached" turns into **Start verification**; it opens the existing verification form as a full-screen panel over My Route (`VerificationsPage` got `embedded`, `leadId`, `onClose`, `onDone`). After submit (and the trip prompt) the panel closes, the pin goes green on the same map, next stop highlighted.
- Assigned Verifications list: leads on today's route show "Start from My Route" instead of a start button; leads not on today's route keep the button (no agent can get stuck).
- `AppShell` keeps agent My Route mounted (hidden) once opened, so visiting other pages and returning costs no new map. It reloads its data on return.
- My Route loads: only the newest request fills the page (a slow older answer used to overwrite a newer day).
- Tested end to end on a test lead (planned for 2026-11-05, assigned to Hari1213): reached -> start -> back -> Collection -> return -> submit -> trip prompt skipped: 1 map created in total; pin turned green. Test lead rejected and deleted by exact id.
