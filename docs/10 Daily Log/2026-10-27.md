- Fix: `StaffPage.handleAddUser` sends role `NGF AGENT` for branch role `collection_agent`; `POST /api/staff` also upgrades `Staff` + `collection_agent` to `NGF AGENT` (creates the Agents record). Existing agent `Hari1213` converted through the API.
- Checked every agent page (verifications, route, customers, collection, trips, notifications, live location) with a test lead assigned to the agent; no errors. Test lead deleted by id.
- Agent My Route: removed the "Re-plan from where I am now" button (and its code). The server `replan` action stays but is no longer used by the agent portal.
- Verification Routes → Agent routes: each agent is a collapsible section (first agent with visits open). Open: stops list on the left (drag / arrows / pins as before), route map on the right (`RouteMap`, sticky on wide screens, stacked on phones). The map follows the on-screen order live, even while dragging; road lines are fetched ~0.6 s after the order settles via `/api/routes/path`. "Map" button renamed "Google Maps" (opens the full route in Google Maps).
- Agent routes map made taller (fills most of the screen height on computers, 480px on phones); RouteMap got an optional heightClass.
- Agent routes: opened agent = fixed-height panel (fits the screen); only the customer list on the left scrolls, the map stays put. Top 'Visit day' card shrunk into one slim row with the tabs (date arrows and branch on the right).

- Agent routes: arranging customers (drag/arrows) only changes the screen and map; a 'Save order' button (with Undo and a 'Not saved yet' note) sends the order to the agent once. Opened sections stay in the page hidden, so reopening costs no new map load; road lines are remembered in the browser for 6 h (lib/clientRoads.ts).
