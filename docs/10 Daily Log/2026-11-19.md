# 2026-11-19

## Speed (perf/eng3)
- `companyTotals()` (`lib/db.ts`, database function `company_totals`, whole-table sums) is kept 45 s per server process with one shared in-flight call; used by staff list, projection, financial analytics, capital, Admin assistant, org chart. Figures can be up to 45 s old.
- `GET /api/staff?agents=1`: agent list only (same permission check), used by the Leads assign-agent pop-up instead of the full staff list (no users, guarantors or totals).
- `lib/supabase-db.ts`: the column-name lookup used for every row read is built once instead of per row (same output).
- Browser: the Sentry code is downloaded only when a key exists, 4 s after load (`instrumentation-client.ts`), and the QR reader (`jsqr`) only when the sign-in QR step opens: smaller sign-in page.
- Staff / custom-page guarantors: the first page picked from permissions is remembered on the device, so the app opens it straight away instead of Notifications first and then jumping. Not tested in a browser; `next build` not run (worktree with linked node_modules).
